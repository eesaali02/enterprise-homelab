# Diagrams

Keep the draw.io source (`.drawio`) and a PNG export of each diagram here, so they can be edited later and still display on GitHub.

At minimum: a physical/virtual diagram (VMs and virtual switches) and a logical diagram (VLANs, subnets, routing). Later phases add a service dependency diagram, the sign-in sequence from Phase 5 and the log-flow diagram from Phase 7. Update a diagram in the same commit as the change it reflects.
